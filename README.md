Desarrollo local
bash# Clonar el repositorio
git clone https://github.com/Jaume92/jaumerrm_web.git
cd jaumerrm_web

# Instalar dependencias
npm install

# Ejecutar en local
npm run dev
Abre http://localhost:3000 en tu navegador.
